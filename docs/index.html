MyEnergi Home Energy

Automated overnight charge management for a Libbi battery on Octopus Flux, with a solar forecast and web dashboard.

Libbi Octopus Flux Solcast Python Self-hosted

One-command install

bash install.sh

click to copy

🌤

Solar forecast

Pulls tomorrow's PV generation estimate from Solcast and factors it into the overnight charge decision.

🔋

Smart charge control

Enables or disables mains charging each night at 23:00 — charges from grid only when solar won't cover the next day's demand.

📊

Web dashboard

Daily kWh summary with charts, recent charge decisions, live SoC, and a one-click manual trigger.

🔒

Discharge always on

Uses the myenergi OAuth API to toggle charge from grid only — the Libbi stays in Normal mode and keeps discharging to the house.

How it works

# runs nightly at 23:00
battery_deficit = LIBBI_CAPACITY − (LIBBI_CAPACITY × soc / 100)
solar_needed = avg_daily_load_kwh + battery_deficit
surplus = tomorrow_forecast_kwh − solar_needed

surplus ≥ 0 → disable mains charging (solar covers it)
surplus < 0 → enable mains charging (shortfall of |surplus| kWh)

Getting started

  1. Clone the repo

    git clone https://github.com/pixelbadger/Pixelbadger.MyEnergi.git

  2. Copy and fill in .env

    Hub serial + API key from myaccount.myenergi.com, Solcast resource ID + key, and your myenergi app login for charge control.

  3. Run the installer

    Installs dependencies and registers a systemd user service that starts on boot.

  4. Open the dashboard

    Browse to http://localhost:5000 — set DRY_RUN=false once you've confirmed the credentials work.
