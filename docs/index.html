MyEnergi Extensions

Automated overnight charge management for a Libbi battery on any tariff with a cheap overnight window (defaults for Octopus Flux) — solar forecasting, weather-aware cold-battery pre-warming, and a web dashboard.

How it works

WhenJob
23:00 Nightly charge decision — Solcast forecast vs. average load + battery deficit → enable or disable mains charging; also fetches the overnight weather forecast and flags a pre-warm if it's cold.
00:10 Pre-warm planning — reads the actual battery cell temperature and SOC, simulates the night's charge minute by minute, and picks the cost-optimal pre-warm lead time.
off-peak − lead Pre-warm enable — one-shot job that starts charging early so the pack is warm when the cheap window opens.

Nightly charge decision

# runs nightly at 23:00
battery_deficit = LIBBI_CAPACITY − (LIBBI_CAPACITY × soc / 100)
solar_needed = avg_daily_load_kwh + battery_deficit
surplus = tomorrow_forecast_kwh − solar_needed

surplus ≥ 0 → disable mains charging (solar covers it)
surplus < 0 → enable mains charging (shortfall of |surplus| kWh)

Cold-weather pre-warm

The Libbi BMS caps charge power by battery cell temperature — roughly 130 W near 0 °C against 4.3 kW when warm — but its built-in heater warms the pack at about 0.24 °C/min while charging. On a cold night a full off-peak window can therefore fail to deliver the planned charge. The planner uses a thermal model calibrated from winter minute-level data to simulate the night's charge at 1-minute resolution and picks the lead time that minimises total cost:

# runs at 00:10, using the measured cell temp + SOC
cost = pre-warm kWh × standard rate
     + window kWh × off-peak rate
     + shortfall kWh × standard rate

→ enable charging at off-peak start − lead

Pre-warm energy isn't wasted — it still charges the battery, just at the standard rate instead of off-peak — so the optimum usually starts only slightly early: around 10 min of lead at 1 °C, 35 min at −5 °C, and none at all when it's mild or the battery is already half-full. Overnight temperatures come from Open-Meteo (no API key needed), and each night's planned lead and measured cell temperature are logged for recalibration.

Getting started

  1. Run the one-line installer

    Clones the repo to ~/myenergi, installs dependencies, and registers a systemd user service that starts on boot. (From an existing checkout, bash install.sh does the same without cloning.)

  2. Enter your credentials when prompted

    Hub serial + API key from myaccount.myenergi.com, Solcast resource ID + key, your myenergi app login for charge control, and your property's latitude/longitude for the weather forecast — written to .env (kept local, never committed).

  3. Start the service

    systemctl --user start myenergi

  4. Open the dashboard

    Browse to http://localhost:5000 — set DRY_RUN=false once you've confirmed the credentials work.
